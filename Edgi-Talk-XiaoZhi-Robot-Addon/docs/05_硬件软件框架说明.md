# 硬件 / 软件框架说明

## 总体架构

```text
用户语音 / 按键 / 网络 AI
          ↓
Edgi-Talk M55
语音识别、联网小智 AI、屏幕表情、情绪状态机、动作决策、串口通信
          ↓ uart5，38400 8N1
HW-221 / TXS0108E 电平转换
          ↓
Arduino UNO
串口解析、角度限制、PWM 输出、舵机缓动、超时安全回中
          ↓
D9：Pan 水平舵机
D10：Tilt 俯仰舵机
```

## 三层分工

| 层级 | 平台 | 主要职责 |
|---|---|---|
| 启动层 | M33 | 完成底层初始化并启动 M55。通常保持稳定，不承担业务逻辑。 |
| 智能交互层 | M55 | 运行 RT-Thread，负责语音、显示、联网 AI、行为状态机和串口动作命令。 |
| 运动执行层 | Arduino UNO | 接收串口命令，控制两路舵机 PWM，执行限位、缓动和安全回中。 |

## 硬件连接

| 信号 | 连接关系 |
|---|---|
| M55 发送 | Edgi CN5 物理 8 脚 TX → HW-221 A1/B1 → UNO D2 RX。 |
| M55 接收 | UNO D3 TX → HW-221 B2/A2 → Edgi CN5 物理 10 脚 RX。 |
| 电平转换 | HW-221 VCCA 接 3.3V，VCCB 接 5V，所有设备共地。 |
| Pan 舵机 | UNO D9 输出 PWM。 |
| Tilt 舵机 | UNO D10 输出 PWM。 |
| 舵机供电 | 使用独立电源，负极与 Edgi、UNO、HW-221 共地。 |

舵机电源不能由 Edgi-Talk 排针或 UNO 的 5V 引脚直接承担。实际电源电压和电流能力需根据舵机型号、负载及机械结构确定。

## 软件数据流

```text
语音输入
  ↓
唤醒词 / 语音识别
  ↓
小智 AI 对话与 MCP 工具调用
  ↓
M55 机器人动作状态机
  ↓
PAN=<角度>,TILT=<角度> 串口命令
  ↓
UNO 指令校验、限位与缓动
  ↓
双舵机头部运动
```

## 串口协议与安全机制

- 通信参数：38400 baud、8 数据位、1 停止位、无校验位。
- M55 发送 `PING`、`CENTER` 或 `PAN=<角度>,TILT=<角度>`。
- UNO 回复 `PONG`、`OK`、`READY` 或错误信息。
- M55 在收到 PONG 和回中 OK 后才将 UNO 标记为在线。
- 系统只允许一条动作指令处于等待确认状态，避免动作堆积。
- UNO 约 5 秒未收到有效指令或心跳时自动回中。
- 通信异常后，M55 取消旧动作、重新探测并回中，不重放断线前动作。

## 可扩展方向

- 增加手臂、底盘或灯光等执行器。
- 引入视觉识别、手势识别或人脸追踪。
- 增加本地小模型，实现离线意图识别。
- 加入情绪记忆和长期陪伴交互逻辑。
- 扩展 MCP 工具，实现更丰富的具身智能动作。
