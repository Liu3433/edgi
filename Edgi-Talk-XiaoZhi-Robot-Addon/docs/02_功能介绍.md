# 功能介绍

## 语音与 AI 交互

- 支持“小瑞”本地唤醒词。
- 支持语音输入、语音识别、联网 AI 问答和语音播报。
- 接入小智 AI 服务，实现自然语言对话。
- 支持按键触发和语音触发交互。

## 屏幕表情与情感表达

- 根据对话状态显示待命、聆听、说话等界面状态。
- 根据 AI 返回的情绪显示开心、思考、困倦、悲伤等表情。
- 将表情、语音和头部动作结合，提升交互反馈的自然度。

## 头部舵机动作

| 用户意图 | 动作能力 |
|---|---|
| 点头 | 头部执行连续俯仰动作。 |
| 摇头 | 头部执行连续水平摆动。 |
| 回正 | 两个舵机回到中心姿态。 |
| 指定姿态 | 分别设置 Pan 水平角度和 Tilt 俯仰角度。 |
| 自动表现 | 聆听、说话、情绪变化时自动切换头部姿态。 |

## 可靠性与安全功能

- Pan 舵机和 Tilt 舵机均设有软件角度范围限制。
- 舵机采用缓动控制，减少瞬时运动冲击。
- M55 与 UNO 通过握手和确认机制建立通信状态。
- 通信期间保持心跳检测，异常后自动重新握手。
- UNO 在约 5 秒未接收到有效命令时自动平缓回中。
- 断线恢复后不会重放断线前的动作，避免意外运动。

## 调试与验证功能

M55 调试终端提供如下命令，可在不联网时验证硬件链路：

```text
robot status
robot center
robot pose 95 95
robot nod
robot shake
robot auto on
robot auto off
```

其中 `robot status` 可查看 UNO 在线状态、目标角度、确认角度、超时和异常计数。
