# 〖2026嵌入式大赛〗Edgi-Talk 小智 AI 情感交互机器人

> 发布前请完成文末“提交前检查”中的视频和开源仓库链接替换。

## 一、项目概述

本项目基于 Edgi-Talk PSoC Edge 平台和 RT-Thread 操作系统，设计并实现了一台具备语音对话、联网 AI、屏幕表情和实体动作反馈能力的小智 AI 情感交互机器人。

机器人可通过“小瑞”唤醒词进入对话，接入小智 AI 服务完成自然语言交互。除语音回复外，系统还会根据对话状态和 AI 动作意图驱动头部舵机完成点头、摇头、回中和指定姿态等动作，并同步显示表情，从而形成“听见用户—理解语义—表达情绪—实体反馈”的完整交互闭环。

项目采用 M33、M55 与 Arduino UNO 三层架构：M33 完成底层启动，M55 运行 RT-Thread 并承担语音、显示、联网和行为决策，UNO 专注于两路舵机的可靠执行。

## 二、功能介绍

### 1. 语音与小智 AI 对话

- 支持“小瑞”本地唤醒词。
- 支持语音输入、联网 AI 问答和语音播报。
- 支持按键和语音两种交互入口。

### 2. 表情与状态交互

- 屏幕显示待命、聆听、说话等交互状态。
- 根据 AI 返回的情绪展示开心、思考、困倦、悲伤等表情。
- 通过表情、语音和动作协同增强陪伴感和反馈感。

### 3. AI 驱动的头部动作

用户可通过自然语言请求机器人执行动作，例如：

```text
请点点头
请摇摇头
把头回正
水平舵机设为 95 度，俯仰舵机设为 100 度
```

M55 将动作意图经串口发送给 UNO，UNO 控制 D9、D10 输出 PWM，驱动 Pan 水平舵机和 Tilt 俯仰舵机。

### 4. 安全与可靠性设计

- Pan、Tilt 均具有软件角度限制。
- 舵机采用缓动控制，减少机械冲击。
- M55 与 UNO 通过握手、确认和心跳维持通信状态。
- 通信异常或 UNO 重启后，系统取消旧动作并重新建立连接。
- UNO 在约 5 秒未收到有效命令时自动缓动回中。

## 三、RT-Thread 使用情况

本项目的核心业务运行在 M55 的 RT-Thread 环境中。

| RT-Thread 能力 | 项目中的应用 |
|---|---|
| 多线程 | 语音、网络、显示、机器人动作等任务并行运行。 |
| 设备框架 | 使用 `uart5` 与 Arduino UNO 进行双向串口通信；`uart2` 保留为调试终端。 |
| IPC / 互斥锁 | 机器人状态、动作请求与串口收发由独立线程和互斥锁协调。 |
| MSH 命令行 | 使用 `robot status`、`robot nod`、`robot shake` 等命令进行离线调试与联调。 |
| 软件组件 | 集成网络、音频、显示、文件系统及小智 AI 交互相关组件。 |

机器人控制线程独占串口资源。语音、网络、AI 和 UI 线程只提交动作意图，避免在回调中阻塞等待硬件响应。

## 四、硬件框架

```text
用户语音 / 按键 / 网络 AI
          ↓
Edgi-Talk M55（RT-Thread）
语音识别、联网小智 AI、屏幕表情、情绪状态机、动作决策、串口通信
          ↓ uart5，38400 8N1
HW-221 / TXS0108E 电平转换
          ↓
Arduino UNO
串口解析、姿态限位、PWM 输出、舵机缓动、超时安全回中
          ↓
D9：Pan 水平舵机
D10：Tilt 俯仰舵机
```

### 主要硬件连接

| 功能 | 连接关系 |
|---|---|
| M55 发送 | Edgi CN5 物理 8 脚 TX → HW-221 → UNO D2 RX |
| M55 接收 | UNO D3 TX → HW-221 → Edgi CN5 物理 10 脚 RX |
| Pan 舵机 | UNO D9 输出 PWM |
| Tilt 舵机 | UNO D10 输出 PWM |
| 逻辑电平 | HW-221 VCCA = 3.3V，VCCB = 5V |
| 接地 | Edgi、HW-221、UNO、舵机电源共地 |

舵机采用独立电源供电，避免大电流负载影响主控板稳定性。

## 五、软件框架与模块说明

```text
语音输入
  ↓
唤醒词 / 语音识别
  ↓
小智 AI 对话与 MCP 工具调用
  ↓
M55 机器人动作状态机
  ↓
PAN=<角度>,TILT=<角度> 串口协议
  ↓
UNO 指令校验、限位和缓动
  ↓
双舵机头部动作
```

| 模块 | 主要职责 |
|---|---|
| M33 启动层 | 底层初始化并启动 M55，日常不承担机器人业务。 |
| 小智交互模块 | 管理唤醒、语音、网络连接、AI 对话和屏幕状态。 |
| MCP 工具模块 | 向小智 AI 提供点头、摇头、回中、姿态设定和状态查询能力。 |
| 机器人控制模块 | 管理动作状态机、串口协议、心跳、确认、超时和自动恢复。 |
| UNO 执行模块 | 执行串口命令，输出两路 PWM，完成限位、缓动和安全回中。 |

## 八、项目亮点与后续计划

本项目将云端大模型的语义理解能力与嵌入式实体动作结合，使 AI 不再只停留在语音回答层面，而是能够通过表情和动作与用户建立更自然的交互。

后续计划包括：

- 增加摄像头，实现视觉感知与人物追踪。
- 增加手臂、底盘、灯光等更多执行器。
- 增加本地离线意图识别，降低网络依赖。
- 扩展 MCP 工具，实现更丰富的具身动作与情感表达。
