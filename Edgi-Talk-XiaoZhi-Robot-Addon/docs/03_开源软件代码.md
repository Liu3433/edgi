# 开源软件代码说明

## 代码组织

| 位置 | 主要内容 |
|---|---|
| `applications/xiaozhi/` | 小智语音交互、网络连接、音频处理、屏幕交互和 MCP 通信。 |
| `applications/robot/` | 机器人动作状态机、串口协议、姿态队列、心跳和断线恢复。 |
| `arduino/EdgiTalkUnoServo/` | Arduino UNO 舵机执行程序。 |
| `tests/robot/` | 串口互操作、协议边界、MCP 工具发现和 WebSocket 回归测试。 |
| `Ai_Read/` | 接线、烧录、联调、AI 工具调用和项目说明文档。 |

## 核心模块说明

### M55 机器人控制模块

`applications/robot/` 是机器人控制核心。它运行独立 RT-Thread 线程，独占 `uart5`，负责：

- 将 AI 或系统状态转换为 Pan/Tilt 姿态命令。
- 向 UNO 发送串口命令，并等待匹配确认。
- 定时发送心跳，判断 UNO 是否在线。
- 在超时、异常回复或 UNO 重启后取消旧动作并重新建立链路。
- 提供点头、摇头、回中和指定姿态等动作接口。

### UNO 舵机执行模块

`arduino/EdgiTalkUnoServo/EdgiTalkUnoServo.ino` 负责执行具体动作：

- 通过 D2/D3 软件串口接收 M55 命令和发送状态回复。
- 通过 D9 输出 Pan 舵机 PWM，D10 输出 Tilt 舵机 PWM。
- 对指令进行格式、范围和异常数据检查。
- 采用缓动方式移动到目标角度。
- 在通信超时后自动回中。

### 小智 AI 工具接口

M55 将以下能力注册为设备 MCP 工具，供小智 AI 服务端发现和调用：

| 工具名 | 作用 |
|---|---|
| `self.robot.action` | 执行 `nod`、`shake` 或 `center` 动作。 |
| `self.robot.set_pose` | 设置 Pan、Tilt 指定角度。 |
| `self.robot.set_auto` | 开启或关闭自动头部动作。 |
| `self.robot.get_status` | 查询舵机链路和 UNO 确认状态。 |

## 开源与复现方式

本项目基于 RT-Thread、Arduino AVR Core、Servo、SoftwareSerial、小智 AI 协议及相关开源组件构建。项目保留了 M55、UNO、测试代码和说明文档，便于复现、学习和二次开发。

构建与测试入口：

```powershell
./tests/robot/run.ps1
./tests/robot/build_uno.ps1
python tests/robot/verify_images.py
```

实际使用时，仍需完成实体硬件的供电、机械限位和串口通信验证。
